# Декомпозитор задач — расширение для Cursor (фронтенд-прототип)

Боковая панель в Cursor: вставляете текст задачи, получаете 3–5 подзадач, правите план и копируете
готовое задание для coding-агента. Рекомендуются только модели, которые вы отметили как доступные.

**Статус.** Реализован фронтенд. Backend пока нет, поэтому по умолчанию включён режим «Демо: без API»:
ответы берутся из встроенных сценариев и **не зависят от текста вашей задачи**. Это видно в интерфейсе
(жёлтая метка). Реальный LLM-вызов появится после подключения backend (см. ниже).

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm run build
npm run package        # создаст task-decomposer-0.1.0.vsix
```

Установка в Cursor: `Cmd/Ctrl+Shift+P` → **Extensions: Install from VSIX…** → выбрать `.vsix`.
В левой панели появится значок «Декомпозитор». Команда **«Декомпозитор: открыть в редакторе»**
открывает то же окно во всю ширину (удобнее для работы с планом).

Режим разработки: открыть папку в Cursor и нажать F5 («Запуск расширения»).
Только интерфейс в браузере, без Cursor: `npm run dev:web` (настройки из `.env.example` → `.env.local`).

## Что умеет

- Левая область: текст задачи (обязательно), стек, критерии, ограничения, фрагмент кода, выбор моделей, предпочтение «Баланс / Качество / Стоимость».
- Правая область: пусто → загрузка (с отменой) → результат / ошибка. Ввод при ошибке не теряется, повтор только вручную.
- Подзадача: название, цель, ожидаемый результат, критерии, зависимости, риск, рекомендуемая модель с пояснением (помечена «предварительно»). Всё редактируется; можно добавлять, удалять, переставлять.
- Проверка плана: обязательные поля, несуществующие и циклические зависимости, максимум 7 шагов. При ошибках копирование и экспорт заблокированы.
- Копирование отдельного задания (цель, критерии, ограничения, входы от зависимостей, контекст, список неизвестного) и всего плана; экспорт `.md` и `.json`.
- Один раунд уточняющих вопросов от модели (`kind: "clarification"`).
- Ручные отметки «Выполнена / Не выполнена»; шаги с невыполненными зависимостями копируются только после предупреждения.
- Черновик и последний план сохраняются локально (в хранилище расширения), на сервер ничего не отправляется, кроме запроса на разбиение.

## Подключение backend

Backend должен реализовать `POST {apiBaseUrl}/v1/plans` по контракту из раздела 10 расширенного ТЗ
(запрос: `schemaVersion, requestId, epic, preference, projectProfile, context, allowedModels, catalog, clarificationAnswers`;
ответ: `kind: "plan"` или `"clarification"`; ошибки: `{ requestId, error: { code, message, retryable, details } }`).

1. Настройки Cursor → `decomposer.apiBaseUrl` (по умолчанию `http://localhost:8787`; вне localhost только `https://`).
2. `decomposer.demoMode` → `false` (или снять галочку «Демо: без API» в панели).
3. Если backend требует авторизацию: команда **«Декомпозитор: задать токен доступа»** (хранится в SecretStorage).

Сетевые запросы делает extension host, а не интерфейс панели (CSP панели запрещает прямую сеть).
Ключ LLM в расширении не используется и не хранится. Интерфейс повторно проверяет ответ по схеме
и отбрасывает рекомендации моделей, которых нет в выбранном списке.

Модели настраиваются в `decomposer.models` (id, displayName, tier: economy / balanced / premium, notes).
Сейчас там заглушки. Подставьте реальные названия, когда будут известны.

## Проверка трёх сценариев приёмки

В панели включите «Демо: без API» и выберите сценарий:

| Сценарий | Что выбрать | Ожидание |
|---|---|---|
| Крупная задача | «Крупная задача (5 подзадач)» | 5 шагов с зависимостями, порядок S1→S5 |
| Простая задача | «Простая задача (1 подзадача)» | одна подзадача |
| Ошибка API | «Ошибка API (503)» | карточка ошибки, ввод сохранён, кнопка «Повторить» |

Дополнительно: «Нужны уточнения» и «Битый ответ модели (цикл)».
Автотесты логики: `npm test` (24 теста: сценарии, валидация, рекомендации, копирование, экспорт).

> Критерий «произвольная задача проходит через реальный LLM API» закрывается только после запуска backend;
> в демо-режиме он **не** проверяется.

## Структура

```
src/extension.ts        extension host: панель, сеть, токен, буфер обмена, экспорт
webview/src/            интерфейс (React + TypeScript), схема Zod, валидация, форматирование
webview/src/mock.ts     демо-сценарии
tests/logic.test.ts     автотесты
```
